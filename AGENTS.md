# Project Guidelines

## Language for Public Repository Content

- Write repository-facing documentation, contributor instructions, maintenance notes, source-code comments, and commit messages in English.
- Keep public metadata and newly added repository files in English unless the content is intentionally localized for end users.
- Localized UI text may use its target language, but every supported locale must express the same meaning and level of detail.

## License and Attribution Wording

- When describing a relationship with an external project, distinguish between an implementation or asset being derived from that project and this application adopting a format or specification defined by that project.
- Do not use wording such as "origin," "original project," "derived from," or "based on" unless there is evidence that the code or assets were actually derived or adapted from the external project.
- When this application supports a format defined by an external project, use wording such as "uses the format defined by" or "adopts the format or specification" so that the relationship is explicit.
- Document the OSS licenses that apply to code and documentation separately from the usage terms that apply to bundled images, models, and other assets.
- Verify that localized license and attribution text describes the relationship with the same meaning and strength in every supported language.
