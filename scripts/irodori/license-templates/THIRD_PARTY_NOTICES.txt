Watermark note:

The Python Irodori-TTS reference implementation can apply SilentCipher
watermarking after synthesis. This browser runtime does not bundle or execute
SilentCipher. Audio generated with this WebGPU runtime is therefore not
watermarked by SilentCipher.

Reference audio note:

No reference audio sample is redistributed with these assets. The application
accepts only user-uploaded reference audio and keeps it in memory for the
current session.
