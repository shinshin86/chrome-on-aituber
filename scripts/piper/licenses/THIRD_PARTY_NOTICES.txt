Components checked but not included in piper-assets-v1:

- espeak-ng
  piper-assets-v1 contains no espeak-ng JavaScript, worker, data file, or
  binary path. The only espeak occurrences are comments in source files and a
  metadata object in tsukuyomi-config.json. The active model configuration has
  phoneme_type: "openjtalk".

- @piper-plus/g2p / g2p-en
  The current upstream piper-plus openjtalk-web package declares
  @piper-plus/g2p, but piper-assets-v1 contains no @piper-plus/g2p package,
  rust-wasm g2p bundle, or g2p-en data. This app's piper provider imports
  SimpleUnifiedPhonemizer from piper/src/simple_unified_api.js and uses
  OpenJTalk for Japanese text.
